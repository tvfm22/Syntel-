# 📊 پروژه بازطراحی صفحه Analytics - نمودارهای حبابی تعاملی

## 🎯 خلاصه پروژه

این پروژه شامل بازطراحی کامل صفحه تحلیلی سیستم خرید است که به کاربران امکان می‌دهد:
- هزینه‌های بخش‌های مختلف را به صورت بصری مشاهده کنند
- روند رشد یا کاهش هزینه‌ها را تشخیص دهند  
- با کلیک روی نمودارها به جزئیات بیشتری دسترسی پیدا کنند (Drill-Down)
- گزارشات را در بازه‌های زمانی مختلف مشاهده کنند

## 🔧 نصب و راه‌اندازی

### پیش‌نیازها
- Python 3.8+
- Django 3.2+
- Django REST Framework
- مرورگر مدرن (Chrome, Firefox, Edge)

### نصب سریع

```bash
# 1. رفتن به مسیر پروژه
cd d:\Syntel\syntel

# 2. نصب وابستگی‌ها (اگر نیاز باشد)
pip install djangorestframework

# 3. اجرای سرور
python manage.py runserver

# 4. باز کردن مرورگر
# http://localhost:8000/analytics/
```

برای راهنمای کامل، [ANALYTICS_QUICK_START.md](./ANALYTICS_QUICK_START.md) را مطالعه کنید.

## 🎯 اهداف و معیارهای موفقیت

### اهداف فنی
- ✅ API های RESTful کارآمد
- ✅ نمودارهای تعاملی و responsive
- ✅ عملکرد بالا (< 2s load time)
- ✅ کد تمیز و قابل نگهداری

### اهداف کسب‌وکار
- ✅ بهبود تصمیم‌گیری مدیران
- ✅ کنترل بهتر هزینه‌ها
- ✅ شفافیت مالی بیشتر
- ✅ کاهش زمان تحلیل داده

### KPIs
- زمان پاسخ API: < 500ms
- زمان رندر نمودار: < 1s
- تعداد کلیک تا داده: 1-2 کلیک
- رضایت کاربر: > 80%
