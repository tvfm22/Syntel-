# خلاصه اجرایی: پروژه بازطراحی صفحه Analytics

## 🎯 هدف پروژه
بازطراحی کامل صفحه تحلیلی سیستم (`/analytics/`) با استفاده از **نمودارهای حبابی تعاملی** برای ارائه بهتر داده‌های هزینه‌ای بخش‌ها و دسته‌بندی‌ها

---

## 🚀 ویژگی‌های کلیدی

### 1️⃣ منوی کناری گزارشات
- قرارگیری در سمت چپ صفحه
- دسترسی آسان به انواع گزارشات
- Navigation ساده و سریع

### 2️⃣ نمودار حبابی هزینه‌های بخش‌ها
- **اندازه حباب** = میزان هزینه
- **رنگ حباب**:
  - 🔴 قرمز: رشد هزینه
  - 🟢 سبز: کاهش هزینه
- **تعامل**: کلیک برای نمایش جزئیات

### 3️⃣ نمودار حبابی دسته‌بندی‌ها (Drill-Down)
- نمایش هزینه‌های دسته‌بندی‌های هر بخش
- متن داخل حباب: مبلغ
- کلیک برای نمایش لیست محصولات

### 4️⃣ لیست تفصیلی محصولات
- جدول کامل محصولات
- اطلاعات: نام، مقدار، قیمت، تاریخ

### 5️⃣ فیلترهای زمانی چندگانه
- 📅 هفتگی
- 📅 ماهانه
- 📅 فصلی (3 ماهه)
- 📅 سالانه
