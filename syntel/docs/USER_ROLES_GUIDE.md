# راهنمای دسته‌بندی و دسترسی کاربران

## تغییرات انجام شده

### ۱. نقش‌های کاربری جدید

نقش‌های زیر به سیستم اضافه شده‌اند:

- **آشپزخانه (kitchen)** - دسترسی به ثبت درخواست خرید
- **بار (bar)** - دسترسی به ثبت درخواست خرید  
- **کانتر (counter)** - دسترسی به ثبت درخواست خرید
- **صندوق (cashier)** - دسترسی به ثبت درخواست خرید
- **تاسیسات (facilities)** - دسترسی به ثبت درخواست خرید
- **خرید (purchasing)** - دسترسی کامل به سیستم خرید
- **مدیر (manager)** - دسترسی کامل به تمام بخش‌ها

### ۲. دسترسی‌های صفحه درخواست خرید

همه نقش‌های زیر می‌توانند درخواست خرید ثبت کنند:
- آشپزخانه
- بار
- کانتر
- صندوق
- تاسیسات
- خرید
- مدیر

### ۳. تعریف کاربر با دسته‌بندی

هنگام ایجاد کاربر جدید در پنل مدیریت یا صفحه تعریف کاربر، می‌توانید:
1. نقش کاربر را از لیست بالا انتخاب کنید
2. نام کاربری و رمز عبور تعیین کنید
3. اطلاعات شخصی (نام و نام خانوادگی) وارد کنید
4. وضعیت فعال/غیرفعال کاربر را مشخص کنید

## مدیریت کاربران از طریق Admin Panel

1. به آدرس `/admin` بروید
2. با حساب مدیر وارد شوید
3. بخش "Users" را انتخاب کنید
4. می‌توانید:
   - کاربران موجود را مشاهده کنید
   - نقش کاربران را تغییر دهید
   - کاربر جدید اضافه کنید
   - کاربران را غیرفعال کنید

## مدیریت کاربران از صفحه مدیریت کاربران

مدیران می‌توانند از طریق صفحه مدیریت کاربران (`/users/`):
1. لیست همه کاربران را مشاهده کنند
2. کاربر جدید ایجاد کنند با انتخاب نقش مورد نظر
3. اطلاعات کاربران را ویرایش کنند
4. کاربران را حذف کنند

## مثال: ایجاد کاربر آشپزخانه

```python
from purchases.models import User

# ایجاد کاربر آشپزخانه
kitchen_user = User.objects.create_user(
    username='chef1',
    password='secure_password',
    first_name='علی',
    last_name='احمدی',
    role='kitchen'
)
```

## نکات مهم

1. **امنیت**: همه کاربران باید رمز عبور قوی داشته باشند
2. **نقش‌ها**: هر کاربر فقط یک نقش دارد
3. **دسترسی‌ها**: دسترسی‌ها بر اساس نقش کاربر تعیین می‌شود
4. **درخواست خرید**: همه دپارتمان‌ها می‌توانند درخواست خرید ثبت کنند
5. **تایید**: فقط مدیر و واحد خرید می‌توانند درخواست‌ها را تایید کنند
